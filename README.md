# Hackapack (Bedrock Resource Pack)

This pack adds strong emissive glow using JSON texture set files:

- Chests: strong orange-like emissive glow.
- Shulkers: strong green emissive glow.
- Hoppers: strong gray emissive glow.
- Mob spawners: strong bright blue emissive glow.

## Installation

1. Zip this folder contents.
2. Rename the zip to `.mcpack`.
3. Open it with Minecraft Bedrock Edition.
4. Activate the resource pack in your world settings.

## Notes

- Glow intensity/color is driven through `*.texture_set.json` files.
- Best visual results are in graphics modes that support PBR/emissive rendering.
